## 2. Données collectées

### Via le formulaire de contact
Lorsque vous remplissez le formulaire de contact, nous collectons :
- Votre nom
- Votre adresse email
- Votre numéro de téléphone (optionnel)
- Le contenu de votre message

Ces données sont transmises via **Web3Forms** et utilisées uniquement pour répondre à votre demande. Elles ne sont jamais revendues ni partagées avec des tiers.

### Via les cookies analytiques
Ce site utilise **Google Analytics (GA4)** et **Google Tag Manager** pour mesurer l'audience de manière anonymisée. Les données collectées incluent : pages visitées, durée de visite, type d'appareil, pays. Aucune donnée personnellement identifiable n'est transmise.

- **Suppression** : demander l'effacement de vos données

Pour exercer ces droits, contactez-nous à : **sitrakanomena1309@gmail.com**
